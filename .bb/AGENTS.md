# Cloudroom project instructions

Read the repository-root AGENTS.md before acting. It is the shared workflow and policy for this project.

This file is Cloudroom's workspace instruction entry point, loaded into provider sessions according to the installed agent-configuration guide. AGENTS.md remains the canonical text so provider-native instructions and Cloudroom use the same policy.

Use this repository to configure the existing Cloudroom installation. An additional application repository is not a prerequisite. Follow explicit user role assignments and do not launch other agents without authorization.
