# 0003: Move the development system from Cloud Room to Orca

Date: 2026-10-27. Status: accepted by the owner in the Orca session that made this change.

## Context

The harness was built around Cloud Room, which disabled native subagents and mediated permissions, approvals, and review delivery through its own app. Much of the procedure in this repository compensated for that. The owner prefers Orca. Orca exposes worktrees, supervised workers, a Run inbox with acknowledgement, worker release, and pull request state through a CLI with version-matched guides, and native subagents work inside Orca-launched Claude.

## Decision

1. Orca replaces Cloud Room. `room-cli` and `.bb/AGENTS.md` are gone; delegation uses `orca worktree create --agent` for handoffs and `orca orchestration worker-start` for supervised work.
2. The harness stays minimal: the tiers of [0001](0001-tiered-protocol.md), the bare-minimum machine of [0002](0002-bare-minimum-harness.md), and the standing merge authorization of [2026-10-25](2026-10-25-agent-merge-and-deploy.md) all stand.
3. Per repository, the harness is enabled as the Claude Code plugin from [11-plugin-install.md](../11-plugin-install.md), not by copying files.
4. Agent worktrees commit and push as `Solvela-bot` through `tools/bot`: a Git identity include scoped to linked worktrees and a credential helper that reads the token from 1Password at push time.
5. The GitHub Action that forwarded bot pull requests to a Cloud Room webhook is removed. Automatic review is to be rebuilt as an Orca automation; until then the orchestrator starts the Codex reviewer as an Orca worker.
6. The guard exempts a single plain `orca` or `orca-ide` command instead of `room-cli`. Everything else in the guard is unchanged.

## Consequences

- Native subagents are allowed for read-only investigation. Writes still go through Orca workers.
- The Cloud Room cloud sandbox, which was the only real write boundary, is gone. An Orca per-workspace environment recipe can replace it and is untested.
- docs/00 to docs/11 remain as history. Decisions 0001, 0002, and 2026-10-25 remain policy.
- Every linked worktree of a repository under `~/Projects` now commits as the bot, including any leftover Cloud Room worktrees. Main checkouts are unaffected.

## Rollback

Revert the commit that landed this decision. The machine-level identity include is removed by deleting the marked block from `~/.config/git/config` and `~/.config/git/orca-bot.gitconfig`.
